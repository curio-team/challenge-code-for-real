00 / De context

Een echte opdracht.

Tijdens Code for Real werken studenten niet aan een casus van school. Ze vormen een developmentteam van twee of drie personen en bouwen acht weken aan een webapplicatie voor een echte opdrachtgever.

Jij hoeft geen uitgewerkt plan mee te nemen. Een concreet probleem of een wens is genoeg. De studenten onderzoeken wat je nodig hebt en doen een voorstel. Hun docent beoordeelt of dat voorstel haalbaar is. Pas daarna start het project definitief.

Het project hoort bij hun opleiding. Een betaling is geen voorwaarde.

01 / Jouw rol

We houden contact.

Als opdrachtgever denk je een paar keer mee. Die momenten houden het project scherp.

Interview
Een eerste gesprek. Je vertelt wie je bent, wat je organisatie doet en waar je tegenaan loopt.

Tussentijds contact
Je schakelt mee als het team een keuze moet maken, of je ontvangt updates over de voortgang. Reken op minimaal één update per week.

Tussenoplevering
Rond week 4 laten ze een werkende tussenversie zien, bij jou op locatie, of op school. Jij geeft feedback.

Eindoplevering en demonstratie
Aan het eind van de acht weken demonstreren ze het resultaat. Jij kijkt mee en vertelt wat je ervan vindt.

Een korte reactie is genoeg. Een update lezen, een vraag beantwoorden of feedback geven bij de demo: daar hebben de studenten het meest aan.
02 / Wat je krijgt

Een werkend prototype, en de code.

Aan het eind van de acht weken heb je iets in handen: een applicatie die je kunt bekijken, en de code erbij.

Een werkend prototype

De studenten bouwen een webapplicatie rond jouw probleem. Je ziet hem werken bij de tussenoplevering en bij de einddemonstratie.

De code erbij

De code wordt beschikbaar gesteld, zodat je die zelf hebt en kunt bewaren. Ook als het project is afgerond.

Het blijft een opleidingsproject. Je kunt het prototype bekijken en de code bewaren. Er kunnen geen rechten aan worden ontleend, zoals bij een product van een webbureau.
03 / Waar het staat

Online, zodat je het kunt zien.

Het prototype staat op hosting en een domein van de studenten of van school. Daar kun je het bekijken, en daar draait de demonstratie.

Wil je het later op je eigen server of domein? Een webbureau kan het voor je overzetten. De studenten leveren het prototype en de code. Het verhuizen naar een eigen omgeving is een volgende stap.

Samen: jij deelt het probleem en denkt mee. De studenten bouwen het prototype, zetten het online en geven je de code.
De afspraak

Een echt gesprek.
Een werkend prototype.
En de code erbij.

Vooraf is duidelijk wat je kunt verwachten: echte samenwerking, een prototype om te bekijken, en de code zodat je die hebt. Het blijft een opleidingsproject.
